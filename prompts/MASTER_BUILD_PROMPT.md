## Mission
Build the complete working application, not a mockup.

## Required stack
- React + TypeScript + Vite
- Node.js + Express + Socket.IO
- YouTube IFrame Player API
- PostgreSQL only where useful
- Vercel frontend
- Render backend

## Workflow
1. Inspect repository.
2. Make a concise implementation plan.
3. Implement Phase 0.
4. Verify.
5. Implement the next phase.
6. Verify after every phase.
7. Never skip tests to move faster.
8. Do not add bonus features before core functionality works.
9. Run build/test/lint at the end.
10. If Ponytail is available, run `/ponytail-review` after feature batches and `/ponytail-audit` before finalization.
11. Use Better Bugs for browser/runtime failures.

## Definition of done
Do not say "complete" until the final checklist is satisfied or the exact remaining blocker is reported.

## Code quality
Prefer simple, direct code. Do not introduce abstractions just because they are theoretically scalable. Preserve required security, validation, tests, accessibility, and error handling.

Never invent deployment URLs, credentials, database URLs, or API keys. Use placeholders until real deployment values exist.
