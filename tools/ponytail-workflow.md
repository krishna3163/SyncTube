# Ponytail Workflow

Use Ponytail to keep the implementation small without removing required safety or correctness.

Recommended:
`/ponytail full`

After meaningful diffs:
`/ponytail-review`

Before final submission:
`/ponytail-audit`

Before handoff:
`/ponytail-debt`

Do not allow Ponytail to remove:
- authorization
- validation
- accessibility
- tests
- required assignment behavior

If the current AI environment supports Ponytail as a plugin/skill, enable it using the official installation instructions for that environment.
