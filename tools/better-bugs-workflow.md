# Better Bugs Workflow

Use Better Bugs for browser-level debugging/reporting.

1. Open the failing page.
2. Reproduce the issue.
3. Open DevTools Network tab if API/WebSocket traffic matters.
4. Create a Better Bugs report.
5. Review screenshot/system/browser/URL and optional HAR information.
6. Give the report/context to the AI coding agent.
7. Fix the root cause.
8. Reproduce and verify.

Do not commit raw reports if they contain cookies, tokens, credentials, or private system information.
